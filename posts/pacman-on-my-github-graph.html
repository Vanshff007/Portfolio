Playing Pac-Man on my GitHub contribution graph

My portfolio shows my GitHub contribution graph: a year of days as a grid of green squares. Click it and it turns into a Pac-Man level. Every day I committed is a pellet. This post is how that works.

From squares to a grid

The heatmap is drawn from a list of days, each with a level from 0 (no contributions) to 4 (my busiest days). The game reads the same data and turns it into columns of 7 rows, one column per week, so the board looks exactly like the graph you just clicked.

const cells = [...Array(h.offset).fill(null), ...h.days];
const cols = Math.ceil(cells.length / 7);
const grid = Array.from({ length: cols }, (_, c) =>
  Array.from({ length: 7 }, (_, r) => cells[c * 7 + r]?.level ?? 0));

The level sets the pellet's value: 10 points per level. Level 4 days are power pellets, so my most productive days are the ones that let you eat the ghosts.

Walls that never trap a pellet

A grid with no walls is boring, so the game adds short wall pieces, 2 to 4 cells long. Two rules keep it fair:

  • Walls only go on empty days. A wall never covers a pellet, so it stays my real graph.
  • Every open cell must stay reachable. After placing a piece, a flood fill starts from Pac-Man's spawn and counts the cells it can reach. If that count is lower than the number of open cells, the piece cut something off, and it is removed.
cells.forEach(([x, y]) => { walls[x][y] = true; });
if (reachable() !== open()) cells.forEach(([x, y]) => { walls[x][y] = false; });
else placed += len;

It stops when walls cover about 30% of the empty days. The random numbers come from a small seeded generator, and the seed is made from the graph itself. So the maze is the same on every visit, and it changes only when my contributions do.

Ghosts that chase with BFS

On a maze, "move toward Pac-Man" in a straight line gets ghosts stuck behind walls. Each ghost instead runs a breadth-first search from its target and builds a distance map of the whole board. At every step it takes the neighbouring cell with the smallest distance.

To make the ghosts feel different, each one aims at a different spot: one goes straight at you, one aims 3 cells ahead of you, one aims 2 behind, one 2 ahead. They also cannot reverse direction, and they take a random turn 15% of the time, so you can get away.

After a power pellet, the same distance map works in reverse: frightened ghosts pick the neighbour with the largest distance and run away, with more random turns (35%).

Catching ghosts that pass through you

Checking only whether a ghost and Pac-Man share a cell is not enough. They move one cell per step, so they can swap cells in the same tick and pass right through each other. A swap counts as a hit too: the ghost is where Pac-Man was, and Pac-Man is where the ghost was.

const same = gh.x === pac.x && gh.y === pac.y;
const swapped = gh.x === pac.px && gh.y === pac.py && gh.px === pac.x && gh.py === pac.y;

The extras

  • Power-ups appear now and then: speed, frozen ghosts, a magnet that pulls in pellets 2 cells away, double points, and an extra life.
  • A camera follows Pac-Man when a year of weeks is wider than the screen, so it works on phones too, with touch controls.
  • The LeetCode graph next to it is a Space Shooter instead: each day I submitted is an enemy block, and brighter blocks take more hits.

The full code is in js/extras/heatmap-games.js. No libraries, just the canvas API.
